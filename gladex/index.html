Day 1 · Part 1

Set up your laptop.

  1. Press the Windows key, type PowerShell, press Enter.
  2. Copy the line below, paste it into PowerShell (right-click pastes if Ctrl+V does nothing), press Enter. If it asks Y/n, press Enter.
  3. When it asks for the Workshop key, type the key from the whiteboard. It starts with wk_.
  4. When it finishes, close PowerShell, open a new one, then type claude and /login.
  5. Inside Claude Code type /setup and name your chief of staff.
Install · Windows PowerShell
$env:CCI_SKILLS='hire,setup'; irm https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.ps1 | iex
If PowerShell blocks it · use Command Prompt
Windows key, type cmd, Enter, paste this.
powershell -NoProfile -ExecutionPolicy Bypass -Command "$env:CCI_SKILLS='hire,setup'; irm https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.ps1 | iex"
On a Mac · Terminal
curl -fsSL https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.sh | CCI_SKILLS=hire,setup bash
Make your desk and hire
Change marketing-hq to your desk: posters-hq, hr-hq, audit-hq, ops-hq, qa-hq, it-hq.
mkdir marketing-hq
cd marketing-hq
claude

Then type /hire inside Claude Code and answer the seven questions.

If something goes wrong. "Running scripts is disabled": use the Command Prompt line. "'claude' is not recognized": close every terminal and open a new one, or restart. Key not accepted: copy it again with no spaces. Login stuck: copy the link it prints into your browser and paste the code back. Office network blocks it: ask IT to allow github.com, githubusercontent.com, anthropic.com and claude.ai, or use a phone hotspot for the install.
Day 1 · Any desk

Five helper prompts.

They work on every desk. Use them all the time.

Fix my brief
Before you run anything big.
Here is my brief: [brief]
Rewrite it with five parts: Goal, Input, Output, Check, Never.
Ask me about anything missing before you start.
Show your source
Check 1, every time there is a number.
For every number in [file], tell me which file and which line it came from.
Mark anything you calculated or guessed.
What were you unsure about
The fastest way to find the weak spot.
List everything in your last answer that you were unsure about,
and what you would need from me to be sure.
Explain what you did
Before you sign it.
Explain what you just did in 3 lines: what you read, what you wrote,
and what you did not check.
Save it as a command
So tomorrow it is one word.

Day 1 · First shift

Your first shift, by desk.

Two starter briefs per desk, built from your survey answers.

Marketing

Harmony · the ads report
Weekly ads report
Export each ad account to ads/ first. CSV is fine.
Read every export in ads/. Make one table per account: spend, leads,
CPL, ROAS, sales. Mark any campaign with CPL above [target].
Then three moves: what to scale, what to fix, what to stop, with the
number behind each. Save as ads/report-[date].md.
Never invent a number that is not in the files.
Week over week
Once you have two reports.
Compare ads/report-[last week].md with ads/report-[this week].md.
List what moved more than 20 percent and the likely reason.
Say which reasons are a guess.

Applicant tracker

Finance

Jayson · the Lakbay Hub audit
Audit checklist
Sample exports only. Never card or bank numbers.
Read the files in audit/. Build a checklist of every item to verify:

Save as audit/checklist-[date].md. Never round or guess a figure.
Reconcile two lists
Bookings against payments, invoices against statements.
Match audit/[list A].csv against audit/[list B].csv by reference number.
Three sections: matched, in A only, in B only, plus amount mismatches.
Save as audit/recon-[date].md.

Day 2 · Part 1

Build its brain.

Open PowerShell, cd into your desk folder, type claude. Then paste this and answer like you are training a new hire.

Let it interview you
Ask me 10 questions about my desk and my one task,
one at a time. Wait for my answer each time.
Then write company.md, desk.md, process.md and rules.md
in a folder called brain/. Use my words, not marketing words.
Then add to CLAUDE.md: read brain/ before every task.
rules.md starter
Paste into brain/rules.md, then add your own.
Never send anything outside without my approval.
Never quote a fare or a price I have not given you.
Never paste client IDs, cards or salaries.
Never guess a number. Say where it came from.
If unsure, stop and ask me.
Every mistake becomes a rule
You just [mistake]. Add a rule to brain/rules.md so it never happens
again. Show me the line you added.
Update the process
When you corrected a step.
Update brain/process.md with the step I just corrected.
Show me the before and after.

Two fonts, four colors, one spacing rhythm, and the things you never do. Then one screen for your one task.

Create DESIGN.md for Gladex.
Fonts: [heading] + [body]
Colors: [background], [text], [accent], [warning]
Never: [one thing you hate]
Write it as rules my AI must follow on every page.
② Build the screen
Ads board, poster maker, applicant tracker, audit checklist, ops report, process board, or agent runner.

The spacing feels [crowded], the [title] is too [small], and
[the table] is hard to scan. Fix those, follow DESIGN.md, nothing else.
