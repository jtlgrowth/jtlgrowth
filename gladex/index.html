Day 1 · Part 1

Set up your laptop.

  1. Press the Windows key, type PowerShell, press Enter. On a Mac: press Cmd + Space, type Terminal, press Enter.
  2. Copy the line for your laptop below (Windows or Mac), paste it in (Windows: right-click or Ctrl+V. Mac: Cmd+V), press Enter. A Mac may ask your laptop password: type it, nothing shows, press Enter.
  3. When it asks for the Workshop key, type the key from the whiteboard. It starts with wk_.
  4. When it finishes, close PowerShell (Mac: quit Terminal with Cmd+Q), open a new one, then type claude and /login.
  5. Inside Claude Code type /setup and name your chief of staff.
