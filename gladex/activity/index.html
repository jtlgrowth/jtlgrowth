Install and setup check

At the end: Claude Code runs on your laptop, with a chief of staff that has a name.

WHY · GWENEverything else in the two days runs on this. A setup problem found now takes 2 minutes. Found later, it eats an hour.
  1. Press the Windows key, type PowerShell, press Enter. On a Mac: press Cmd + Space, type Terminal, press Enter.A window with a blinking line.
  2. Copy this line, right-click inside PowerShell to paste, press Enter. On a Mac, use the Mac line under the steps and paste with Cmd+V. 
    irm https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/w/claude.ps1 | iex
    Lines of text scrolling. If it asks Y/n, press Enter. If Windows asks for permission, click Yes.
  3. When it asks for the Workshop key, type the key from the whiteboard.It keeps installing. This takes a few minutes.
  4. When it finishes, close PowerShell (Mac: quit Terminal with Cmd+Q). Open a new one.A fresh, empty window.
  5. Type claude and press Enter. Then type /login and finish in the browser.Claude Code waiting for your message.
  6. Type /setup. Answer the three questions: its name, how it talks, what it asks you first.Every reply now starts with that name.
  7. Check your buddy's laptop: installed, opens, logged in, named.Both laptops pass all four.

Done when: both laptops pass all four checks. First pair to shout "Hired!" wins the install race.

On a Mac? Open Terminal and paste this instead. If it asks for a password, type your laptop password (nothing shows while you type) and press Enter. A popup about Command Line Tools? Click Install, wait, then paste the line again.

Activity 3 · 5 minutes · on paper · now for your own desk

Write the brief for your one task

At the end: five lines that tell your employee exactly what to do.

WHY · GWENAI is only as good as your instructions. Vague brief, vague output. Five parts means it cannot guess what you meant.
  1. Goal: what done looks like, in one line."A weekly ads summary management can read in 2 minutes."
  2. Input: which file or folder it reads."Last week's exports in ads/."
  3. Output: the format and the filename."One table plus 3 moves, saved as ads/report.md."
  4. Check: how you will know it is right."Totals match the export."
  5. Never: what it must not do or guess."Never invent a number that is not in the file."
  6. Stuck? Paste this into Claude Code with your rough idea. 
    Here is my brief: [brief]
Rewrite it with five parts: Goal, Input, Output, Check, Never.
Ask me about anything missing before you start.
    It asks what is missing, then gives you a clean brief.

Data rule: no passport or ID numbers, card or bank details, salaries or passwords. Use "Client A" and sample data.
