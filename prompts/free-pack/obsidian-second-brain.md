# Obsidian second brain setup

Creates an Obsidian vault folder with a daily note template, a clients folder, an inbox note, and wires your CLAUDE.md to read it.

## The prompt

Paste this into Claude Code.

```
I want a second brain in Obsidian (a free notes app, obsidian.md) that you can read and write to.

Ask me two things first:
1. Where should the vault folder live on my computer.
2. What do I call the folder (a name like a business name or "notes" is fine).

Then do this yourself, do not just tell me how:
1. Create the folder, and inside it: a "Daily" folder, a "Clients" folder, and an "Inbox.md" file for anything I drop in without sorting it.
2. Create "Daily/template.md" with a simple daily note shape: date, three priorities, notes, open loops.
3. Create today's daily note from that template.
4. Add a short section to my CLAUDE.md (or create one if I do not have one) that tells you this vault exists, where it lives, and that you should read the Inbox and today's daily note when I ask what is going on.

When you are done, tell me the exact folder path, list the files you created, and tell me how to open the vault in the Obsidian app (I install Obsidian myself, you do not need to).

To check it worked: open the vault folder in Finder or Obsidian and confirm Daily, Clients, Inbox.md and today's dated note are all there.
```

## How to check it worked

open the vault folder in Finder or Obsidian and confirm Daily, Clients, Inbox.md and today's dated note are all there.
