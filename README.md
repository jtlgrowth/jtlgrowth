## We run the firm on the thing we sell

Two people and an AI workforce. 27 AI seats work the repetitive half of the business daily,
each with a written job description, real tools and a review loop. That is the operating model,
not a pitch line: the agency ships like a ten-person shop because most of the shop is software
we built and maintain. The repos pinned below are pieces of it.

The open source, all MIT, each one built because we needed it.

- [jtl](https://github.com/jtlgrowth/jtl), the Claude Code toolkit we run: pressure-test plans, security review, goal planning, RAG tuning, TDD repair. Zero dependencies.
- [securitymaxx](https://github.com/jtlgrowth/securitymaxx), ten security checks for a shipped app where every PASS cites a file and line.
- [hq-base](https://github.com/jtlgrowth/hq-base), your AI team's office in 3D, on your own laptop.
- [flowgraph](https://github.com/jtlgrowth/flowgraph) and [microtoast](https://github.com/jtlgrowth/microtoast), animated diagrams and accessible toasts in no framework at all.
- [claude-code-installer](https://github.com/jtlgrowth/claude-code-installer) and [codex-cli-installer](https://github.com/jtlgrowth/codex-cli-installer), one command each, on any OS.
