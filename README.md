## What we build

Four tiers, installed in order, because each one only works when the one below it does.

| Tier | What it is |
|---|---|
| **1. Funnels and websites** | Hand-coded pages engineered around one question: does the visitor take the next step. Copy, tracking and consent wired at build time, not bolted on. |
| **2. Automation systems** | CRM and pipeline automation, lead routing, follow-up, tool-to-tool plumbing. Failure paths designed in: retries, alerts, human fallback. |
| **3. AI employees** | Trained agents that answer, qualify and follow up inside inbox, chat and CRM. Automated replies disclose that they are automated, by policy. |
| **4. Ops portals** | People, work in flight and revenue on one screen. Agent seats reporting into the same board the humans read. |

Built by hand on Claude, GPT-5, n8n, GoHighLevel, Supabase, FastAPI and Playwright.
No template, no page builder, no drag-and-drop.
