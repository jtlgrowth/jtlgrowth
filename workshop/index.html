Workshop · Batch 1 · Aug 22 to 23, 2026 · Novel Hotel BGC

From operator to orchestrator. Shipped.

Two build days in BGC with Gwen Ayala, Faith Natividad and Jamz Jamorol. Day one every founder built an AI employee for their own business and put it live on the internet. Day two they gave it a UI system of their own and published again.

Scroll

What this was

Most founders had used AI to write a message or summarize a document. Few had used it to build and ship a real tool: something with a live link, running on their own laptop, doing a job.

This room closed that gap in two days. Every founder left with software they built themselves, deployed, and theirs.

None of it replaced a team. It took the repetitive work off the team's plate: the same reply forty times, the message at 11pm.

The record

  • Two build days, Aug 22 and 23, 2026, at Novel Hotel BGC
  • Three founders on the floor the whole time: Gwen, Faith and Jamz
  • Sponsor booths lining the room both days
  • Every builder shipped a live link before Day 1 ended

What happened, day by day

Day 1

Building an AI employee

  • The difference between a tool and an employee: a job, instructions, tools, and a place to work
  • Claude Code set up on every founder's own machine, Mac and Windows, walked through live
  • A build prompt written for each business: what it sells, who buys it, what the tool should do
  • A single-page tool built, no setup and no accounts for the person using it
  • Shipped live with a public link before the session ended

Day 2

Your own UI system

  • Why every AI-built page looks AI-made: same fonts, same gradients, same cards
  • What a UI system actually is: fonts, colors, spacing, and rules you never break
  • The JTL AgentKit installed inside Claude Code, two commands
  • Each system written down as a DESIGN.md file the AI must follow on every page
  • Applied to Day 1's tool, judged by the reviewer agent against the founder's own rules, and published again
