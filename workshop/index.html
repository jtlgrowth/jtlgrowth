What this was

Most founders had used AI to write a message or summarize a document. Few had used it to build and ship a real tool: something with a live link, running on their own laptop, doing a job.

This room closed that gap in two days. Every founder left with software they built themselves, deployed, and theirs.

None of it replaced a team. It took the repetitive work off the team's plate: the same reply forty times, the message at 11pm.

The record

  • Two build days, Aug 22 and 23, 2026, at Novel Hotel BGC
  • Gwen and Jamz on the floor the whole time, with a floor team at the tables
  • Sponsor booths lining the room both days

01

Day 1

Building an AI employee

  1. The difference between a tool and an employee: a job, instructions, tools, and a place to work
  2. Claude Code set up on every founder's own machine, Mac and Windows, walked through live
  3. A build prompt written for each business: what it sells, who buys it, what the tool should do
  4. A single-page tool built, no setup and no accounts for the person using it
  5. Shipped live with a public link before the session ended

02

Day 2

Your own UI system

  1. Why every AI-built page looks AI-made: same fonts, same gradients, same cards
  2. What a UI system actually is: fonts, colors, spacing, and rules you never break
  3. The JTL AgentKit installed inside Claude Code, two commands
  4. Each system written down as a DESIGN.md file the AI must follow on every page
  5. Applied to Day 1's tool, judged by the reviewer agent against the founder's own rules, and published again
