01Setup

One command.
That’s the setup.

It installs the Claude Code CLI, the tools it needs, and our hire skill — then checks the result actually works. Copy the line for your computer, paste it into the terminal, press Enter.

Mac · or Linux
Open Terminal — press ⌘ Space, type "Terminal", press Enter
$ curl -fsSL https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.sh | CCI_SKILLS=hire bash
Windows
Open PowerShell — press the Windows key, type "PowerShell", press Enter
> $env:CCI_SKILLS='hire'; irm https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.ps1 | iex
02Then

Four steps and you’re working.

  1. Close the terminal and open a new one. Not optional — the new window is what picks up the command that was just installed.
  2. Type claude and press Enter.
  3. Type /login and sign in.
  4. Type /hire to check the skill loaded.
03If it doesn’t work

Three things go wrong. All three are quick.

claude: command not found

You’re in the terminal window you had open before installing. Close it, open a new one, try again.

Windows says running scripts is disabled

Paste Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass first, press Enter, then paste the install command again. It applies to that one window only.

It finished, but /hire isn’t there

The skill needs Node. Install the LTS build from nodejs.org, open a new terminal, then run npx skills add https://github.com/jtlgrowth/hire --skill hire.

Anything else — the full manual walkthrough, every step separately, is here. Or send us the last 20 lines of the output at hello@jtlgrowth.com — the error text is the useful part, a screenshot of the whole window isn’t.

04What you just ran

Nothing hidden.

Both scripts are open source, MIT, and short enough to read before you run them: the installer and the hire skill. The installer doesn’t download Claude Code itself — it calls Anthropic’s own installer, which fetches a checksum-verified binary. Running the command again later is safe: it updates what’s out of date and leaves everything you’ve set up alone.
